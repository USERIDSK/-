# 音视频批量转换工具 (Media Converter)

一个基于 FFmpeg 的轻量级音视频批量转换工具，支持格式互转、音频提取、视频画质调整、音频倍速调整等功能。
提供 **C++ (Win32 API)** 和 **C# (WinForms)** 两个版本源码，无需安装庞大的 IDE 即可编译。

## ✨ 功能特性
- 支持批量添加文件或文件夹（自动扫描子目录）。
- 支持按格式过滤文件并一键全选。
- 支持音视频格式互转（MP4、MKV、AVI、MP3、WAV、AAC、FLAC）。
- 支持提取视频中的音频（例如 MP4 转 MP3）。
- 支持调整视频画质（CRF）、分辨率、帧率。
- 支持调整音频码率、采样率、声道。
- 支持视频滤镜（亮度、对比度、饱和度、锐化）。
- 支持音频倍速（变速不变调）和音量调整。
- 自动处理重名文件，不会覆盖已有文件。
- 1. 亮度 (Brightness)

· 基准值（不变）：填 0 或者直接留空。
· 可选范围：-1.0 到 1.0
· 填法建议：
  · 如果视频偏暗，想稍微提亮：填 0.1 或 0.2（千万别超过 0.3，否则画面会发白，丢失暗部细节）。
  · 如果视频偏亮，想压暗：填 -0.1 或 -0.2。
· 核心机制：你的代码里写了 if (brightStr != "0")，所以只要你填的是 0，FFmpeg 就不会执行亮度滤镜。

2. 对比度 (Contrast)

· 基准值（不变）：填 1.0 或者 1，或者留空。
· 可选范围：0.0 到 3.0
· 填法建议：
  · 想让画面更有立体感、黑白分明：填 1.2 到 1.5。
  · 想让画面变得柔和（降低对比度）：填 0.8。
· 核心机制：你的代码里 if (contrastStr != "1.0" && contrastStr != "1")，填 1 就不会触发。

3. 饱和度 (Saturation)

· 基准值（不变）：填 1.0 或者 1，或者留空。
· 可选范围：0.0 到 3.0
· 填法建议：
  · 想让色彩更鲜艳：填 1.2 到 1.5。
  · 想要复古、褪色效果：填 0.5。
  · 想要黑白电影效果：填 0（注意，填0也是生效的，代码会识别为不是"1.0"而应用滤镜）。
· 核心机制：和对比度类似，1.0 或 1 是原色。

4. 锐化 (Sharpen)

· 基准值（不变）：直接留空（不要填 0，因为代码里 if (sharpenStr != "") 是只要非空就生效）。
· 可选范围：0.0 到 5.0（实际视频处理中，建议 0.2 到 1.5 即可）
· 填法建议：
  · 视频有点模糊，想略微增强边缘细节：填 0.5。
  · 视频非常模糊（如老旧DV拍摄），想大幅度锐化：填 1.0 或 1.5。超过 2.0 画面会布满噪点和锯齿。
5.倍速

 填 0.5 ~ 2.0：直接生效，完美运行。
· 填 2.0 ~ 4.0：代码会自动帮你拆成两个滤镜（比如你填 3.0，代码后台会拼成 atempo=2.0,atempo=1.5），但音质会有所下降。

## 📦 依赖环境
本程序**不包含** FFmpeg 核心组件，请在运行前自行准备：

1. 前往 [FFmpeg 官网](https://ffmpeg.org/download.html) 或 [BtbN 的 GitHub 构建页](https://github.com/BtbN/FFmpeg-Builds/releases) 下载 `ffmpeg.exe`。
2. **方式一（推荐）**：将本程序放在ffmpeg.exe所在的同一个文件夹下。
3. **方式二**：将 `ffmpeg.exe` 所在目录添加到系统环境变量 `PATH` 中。

## 🚀 如何使用
1. 下载右侧 **Releases** 中最新的 `MediaConverter.exe`。
2. 将 `ffmpeg.exe` 放到同一个文件夹。
3. 双击运行 `MediaConverter.exe`。
4. 点击“添加文件”或“添加文件夹”，选择你要转换的文件。
5. 选择输出目录和输出格式，点击“开始转换”。
